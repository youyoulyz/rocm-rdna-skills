# Skill Card

## Description
Install the full vLLM serving stack on AMD RDNA consumer GPUs (RX 7900 XTX / gfx1100) from wheels: Python 3.14 venv, TheRock pip-built ROCm 7.14 SDK, ROCm PyTorch 2.11 (torch[device-gfx1100]==2.11.0+rocm7.14.0), flash-attn, and the AMD vLLM RDNA wheel via uv. Handles venv creation, wheel installs, environment variables, and verification.
