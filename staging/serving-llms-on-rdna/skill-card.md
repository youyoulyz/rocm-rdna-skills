# Skill Card

## Description
Serve LLMs on AMD RDNA consumer GPUs (RX 7900 XTX, RX 7000/6000/9000 series) using vLLM (pip or Docker) or llama.cpp (Docker or compiled from source). Handles GPU detection, environment validation, model selection under 24 GB VRAM constraints, launch, and health verification.
